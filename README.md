# 橙光攻略整理器 | Orange Guide Organizer

一个用于橙光作品页的 Chrome 扩展：整理评论攻略，支持逐页抓取、搜索、分类、点赞排序、总花数筛选和本地收藏。

> 目前可通过 Chrome 开发者模式手动安装体验。扩展仅适用于 `https://www.66rpg.com/game/*`。

## 本地安装（未上架时）

1. 点击本页右上角 **Code → Download ZIP**，并在电脑上解压整个 ZIP 文件。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角的 **Developer mode（开发者模式）**。
4. 点击 **Load unpacked（加载已解压的扩展程序）**，选择解压后的项目文件夹（其中应直接看到 `manifest.json`）。
5. 打开一个 [橙光作品页](https://www.66rpg.com/game/982061)，在页面内展开评论区，再点击扩展图标开始使用。
6. 只整理当前页时，先滚动加载评论并点“重新扫描”；整理所有分页时，点“抓取全部页”。扩展会从第 1 页开始逐页读取、显示进度并自动去重，也可以随时停止。

若 Chrome 显示首次使用说明，请阅读后选择是否同意扫描当前已加载的评论。无需登录扩展或创建账号。

## 功能

- 从第 1 页开始逐页抓取评论，显示进度、自动去重，并可中途停止。
- 根据攻略主题筛选、搜索评论。
- 按点赞数排序，并按总花数筛选。
- 收藏评论，按作品查看和创建收藏文件夹。
- 导入 JSON 收藏备份，或导出 JSON 备份和 HTML 阅读页。
- 在当前评论仍已加载时跳回原评论。

## 隐私与范围

- 仅在橙光作品页运行；常规扫描读取页面中已经加载的评论。点击“抓取全部页”后，会依次切换评论分页并读取各页评论。
- 收藏保存在浏览器本地；不上传评论，不调用 AI。
- 扩展源码随本仓库提供。用户可先用开发者模式本地安装；Chrome Web Store 上架审核通过后，也可从商店安装。

## 开发

这是一个无构建步骤的 Manifest V3 扩展。修改源码后，在 `chrome://extensions` 中点击扩展卡片上的刷新按钮即可加载改动。

主要文件：`manifest.json`、`content.js`、`styles.css`。
