# 橙光攻略整理器 | Orange Guide Organizer

一个用于橙光作品页的 Chrome 扩展：整理评论攻略，支持逐页抓取、搜索、分类、点赞排序、总花数筛选、本地收藏和本机 AI 去重。

> 目前可通过 Chrome 开发者模式手动安装体验。扩展仅适用于 `https://www.66rpg.com/game/*`。

## 本地安装

1. 点击 GitHub 仓库 **Code → Download ZIP**，解压整个文件夹。
2. 在 Chrome 地址栏打开 `chrome://extensions`，打开 **Developer mode（开发者模式）**。
3. 点击 **Load unpacked（加载已解压的扩展程序）**，选择其中直接包含 `manifest.json` 的文件夹。
4. 打开橙光作品页并展开评论区，点击扩展开始使用。

## 可选：安装本机 AI

AI 去重需要在自己的 Windows 电脑安装 [Ollama](https://ollama.com/download/windows)。安装后从 Windows“开始”菜单打开 Ollama。首次点击“AI 去重整理”并完成连接后，若尚未安装模型，点击扩展提供的“一键下载模型”（约 2.5 GB）。若不安装 Ollama，搜索、筛选、收藏和导出等原有功能仍可使用。

模型仅返回重复分组编号；扩展显示原评论，不让模型改写。不同阶段、条件、数值和路线会尽量分开保留。每组展示全部作者和来源，代表原文优先选赞数较高的评论。结果只在当前面板展示，不自动收藏或保存。

## 功能

- 逐页抓取评论，可随时停止，并保留已抓取内容。
- 按主题筛选、搜索评论、点赞排序和总花数区间筛选。
- 收藏评论、按作品浏览、创建文件夹，并导入或导出收藏。
- 选择多条评论，使用本机 Ollama 做重复项分组；复制整理结果。

## 隐私与范围

- 扩展只在橙光作品页读取已加载的评论及页面展示的相关信息。
- 收藏保存在 Chrome 扩展本地存储。不会把评论发送给开发者服务器或云端 AI。
- 使用 AI 时，所选评论正文和临时编号会发送到你电脑上的 Ollama；作者、赞数和来源信息留在扩展中。AI 结果不持久保存。

## 开发

这是无构建步骤的 Manifest V3 扩展。修改后在 `chrome://extensions` 中刷新扩展。主要文件：`manifest.json`、`content.js`、`styles.css`、`ai-worker.js`。
