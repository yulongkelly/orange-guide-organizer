# 橙光攻略整理器 | Orange Guide Organizer

一个用于橙光作品页的 Chrome 扩展：整理评论攻略，支持逐页抓取、搜索、分类、点赞排序、总花数筛选、本地收藏，并按游戏当前年月定位攻略里的对应内容。

> 目前可通过 Chrome 开发者模式手动安装体验。扩展仅适用于橙光作品页及其游戏页面。

## 本地安装

1. 点击 GitHub 仓库 **Code → Download ZIP**，解压整个文件夹。
2. 在 Chrome 地址栏打开 `chrome://extensions`，打开 **Developer mode（开发者模式）**。
3. 点击 **Load unpacked（加载已解压的扩展程序）**，选择其中直接包含 `manifest.json` 的文件夹。
4. 打开橙光作品页并展开评论区，点击扩展开始使用。

## 功能

- 逐页抓取评论，可随时停止，并保留已抓取内容。
- 按主题筛选、搜索评论、点赞排序和总花数区间筛选。
- 收藏评论、按作品浏览、创建文件夹，并导入或导出收藏。
- “定位”标签页：把评论（卡片上的“加入定位”）、本地 `.md`/`.txt` 文件或粘贴的文字加入为攻略副本（不影响收藏），勾选要用的攻略（可多份，也可“只用这份”），再按游戏当前年月显示时间线并展开当前月份，可预览上一月、下一月。导入的 `.md` 文件按 Markdown 显示，`## 一月`、`## 七月、八月` 这样的标题会整节归到对应月份；评论、粘贴文字和 `.txt` 保持纯文本；没有时间的内容放进“通用”。其他标签页不做时间高亮。
- 适配不同游戏：游戏不用年月时，在 `.md` 标题末尾写上游戏里显示的文字作为关键词，比如 `## 暑假第一周 [第1周]`。一节可以写多个 `[第1周|第2周]`，也可以写范围 `[第4-8周]`，数字写法不限（第一周、第1周相同）。如果同样的周数也会跟在月份后面，写 `[第1周!月]`，它能匹配“第1周 周一”，但不匹配“9月 第1周”。游戏屏幕上出现这些短文字时会定位到对应小节，长对话不算。也可以展开任意一节点“设为当前”手动定位。
- 直接修改攻略：展开“定位”里的任意一节点“编辑”，在卡片里改这一节（含标题，比如把 `[第1周]` 改成 `[第1周|第2周]`）；在攻略列表点“全文”再点“编辑全文”可改整份。编辑时显示 Markdown 原文，回车只是换行；点“保存”才写入，之后无法撤销，“取消”放弃改动。有未保存改动时，切换标签页、关闭面板、点别处或刷新页面前会提示；保存失败（存储已满）会保留文字并显示错误。保存后重新分节，新的关键词会发给游戏。每份攻略的“导出”按钮下载已保存的内容（`.md` 攻略导出 `.md`，其余导出 `.txt`）。
- 读取游戏当前年月：游戏页面里的小脚本只读取画面上要显示的日期和境界文字（如“庆和22年9月”），并把解析后的年、月、境界告诉扩展；不读取也不转发其他游戏内容。也可以手动输入年月，“跟随游戏时间”关闭时以手动值为准。游戏状态页不打开时读取值可能过期，面板会显示上次更新时间。

## 隐私与范围

- 扩展只在橙光作品页读取已加载的评论及页面展示的相关信息。
- 收藏保存在 Chrome 扩展本地存储。不会把评论发送给开发者服务器或云端。
- 定位用的攻略和游戏时间只在本机保存（按作品编号），不会上传。

## 开发

这是无构建步骤的 Manifest V3 扩展。修改后在 `chrome://extensions` 中刷新扩展。主要文件：`manifest.json`、`content.js`、`time-points.js`、`markdown.js`、`game-bridge.js`、`styles.css`。测试：`node --test`。
